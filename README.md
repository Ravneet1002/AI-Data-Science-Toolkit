# AI & Data Science Toolkit

## 📌 Project Overview

AI & Data Science Toolkit is a Python-based desktop application developed using Tkinter.

The application allows users to load CSV datasets, perform data analysis, visualize data, and apply machine learning for student marks prediction.

## ✨ Features

### Dataset Management
- Load CSV datasets
- View complete dataset
- Display dataset information
- Check missing values
- Generate data cleaning reports
- Export datasets as CSV files

### Data Analysis
- Statistical summary
- Calculate averages
- Minimum and maximum values
- Basic data insights

### Data Visualization
- Histogram
- Scatter plot
- Correlation heatmap

### Machine Learning
- Student marks prediction
- Multiple Linear Regression
- Model evaluation
- R² Score
- Mean Absolute Error
- Predicted vs Actual visualization

## 🛠️ Technologies Used

- Python
- Tkinter
- Pandas
- Matplotlib
- Scikit-learn

## 📊 Dataset

The project uses a student dataset containing the following features:

- Age
- Study Hours
- Attendance
- Assignments
- Marks

The dataset contains 20 student records.

## 🤖 Machine Learning Model

The project uses Multiple Linear Regression to predict student marks.

### Input Features

- Age
- Study Hours
- Attendance
- Assignments

### Target Variable

- Marks

The model is evaluated using:

- R² Score
- Mean Absolute Error (MAE)
